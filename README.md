## 🌟 Overview

A high-performance, responsive personal portfolio built with a cutting-edge **Cyberpunk / Sci-Fi HUD aesthetic**. It highlights featured software projects, technical skillsets, academic milestones, and an interactive AI terminal assistant.

### 🚀 Key Highlights
- **Interactive Cyberpunk UI**: CRT scanline effects, glowing vector accents, and a dynamic HTML5 Canvas particle backdrop.
- **Embedded AI Assistant**: Interactive terminal-style assistant for querying portfolio details, background, and tech stack.
- **Synthesized Ambient Audio**: Web Audio API sound effects and cyber ambient audio toggles.
- **ATS Resume Viewer**: Integrated clean curriculum vitae with one-click direct Google Drive download and preview.
- **Comprehensive Project Showcase**: Detailed architecture modals, tech stacks, and live links for featured works:
  - **Project Sentinel**: Python multi-threaded biometric security, OpenCV Face ID & AI-assisted static vulnerability scanner.
  - **Jade Lantern**: Responsive restaurant web app with custom CSS 3D flip-book menu.
  - **Birthday Experience**: 22-level interactive desktop escape-room web game built on HTML5 Canvas.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion
- **Visuals & Effects**: HTML5 Canvas (2D Particles), CSS 3D Transforms, Lucide Icons
- **Audio**: Web Audio API (real-time synthesizer)
- **Tooling**: Vite, ESLint

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/auratech01/malaika-fatima-portfolio.git

# Navigate to project directory
cd malaika-fatima-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
