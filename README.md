# Malaika Fatima — Personal Portfolio

A modern, high-performance personal developer portfolio built with a futuristic Cyberpunk & Sci-Fi HUD aesthetic. Showcases software engineering projects, technical skillsets, and academic background.

## 🚀 Live Demo
- **Portfolio Website:** https://auratech01.github.io/malaika-fatima-portfolio/

---

## 🛠️ Tech Stack & Technologies

- **Frontend:** React 19, TypeScript, Tailwind CSS
- **Graphics & Animation:** HTML5 Canvas (2D Particles), CSS 3D Transforms, Lucide Icons
- **Audio Integration:** Web Audio API
- **Build Tooling:** Vite, ESLint

---

## 🌟 Featured Projects Included

### 3. Birthday Experience — 22-Level Interactive Web Game
- 22-level interactive canvas puzzle and escape-room-style game engineered for desktop browsers.

- [Live Demo](https://auratech01.github.io/birthday-experience/)

## 💻 Local Development Setup

To run this project locally on your machine:

```bash
# Clone the repository
git clone https://github.com/auratech01/malaika-fatima-portfolio.git

# Navigate to project directory
cd malaika-fatima-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```
